# **手寫數字識別系統 (CNN + Flask)**

本專案實作了從數據訓練到 Web 端部署的完整流程，利用 **CNN (卷積神經網絡)** 辨識 **MNIST** 手寫數字，並透過 **Flask** 提供直覺的網頁操作介面。

---

## **專案結構說明**

* **模型層 (`mnist_cnn.py`)**：定義核心網路架構，並封裝了模型權重的存取邏輯。
* **訓練層 (`train.py`)**：負責載入數據集、執行模型訓練，並將結果持久化為模型檔。
* **應用層 (`predict.py`)**：用於測試單張圖片的判讀效果。
* **網頁端 (`app.py`)**：基於 Flask 實作的介面，支援使用者上傳圖片並即時回傳預測結果。
* **環境設定 (`requirements.txt`)**：列出執行本專案所需的所有依賴套件。

---

## **快速執行流程**

### **1. 環境準備**
在開始之前，請先確保已安裝必要的套件：
`pip install -r requirements.txt`

### **2. 模型訓練**
請依序執行以下程式碼，以產出訓練好的權重檔 (`mnist_cnn.pth`)：
* 執行 `mnist_cnn.py` 初始化結構。
* 執行 `train.py` 開始訓練並儲存模型。

### **3. 啟動 Web 服務**
執行 `app.py` 啟動 Flask 伺服器，接著即可透過瀏覽器上傳手寫數字圖片進行辨識測試。
